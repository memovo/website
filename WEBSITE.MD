# 🎵 Shoolin Music Website — Design & Development Context

## Overview
This repository powers **[shoolinmusic.com](https://shoolinmusic.com)** — the personal website of **Shoolin Vora**, a 9-year-old composer whose work spans **classical** and **cinematic** styles.  
The goal is to showcase his creativity and musical depth in a way that feels **artistic, cinematic, and authentic** — not overly “childish” nor overly “formal.”

---

## 🎯 Goals
- Present Shoolin as a young but serious **composer and pianist**.  
- Provide easy access to his **featured track releases** (starting with *The First One*).  
- Build anticipation for future works and collaborations.  
- Offer a polished, cinematic, modern experience while keeping navigation minimal.  
- Keep everything simple to update and deploy via GitHub Pages.

---

## 🧩 Technical Setup
- **Framework:** React (Create React App)
- **Hosting:** GitHub Pages (branch: `gh-pages`)
- **Domain:** [shoolinmusic.com](https://shoolinmusic.com)
